# Case Doc Tracker

A lightweight, shareable checklist tracker for case documentation. Define the categories of documents a case needs, check items off as they're collected, and generate a status report showing what's done and what's outstanding.

Built so the status can be shared with someone outside the investigation — e.g., a customer service rep — so they can answer "what's still needed from the customer?" without repeatedly pulling the investigator away from casework.

No fraud logic, no scoring, no prescribed methodology — just a tracking utility for a checklist you define yourself. Includes a browser-based live demo (`index.html`) that runs entirely client-side; nothing is saved or uploaded.
